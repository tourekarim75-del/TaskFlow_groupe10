Organisation du projet TaskFlow

1. Présentation

TaskFlow est une application Java en mode console permettant de gérer des tâches.

2. Organisation du travail

Le projet est réalisé en équipe. Le travail est organisé à l'aide de GitHub Issues, du tableau de suivi GitHub Projects et des pull requests.

3. Répartition des responsabilités

Chaque membre de l'équipe participe au développement, à la vérification ou à la documentation selon les tâches qui lui sont attribuées.

4. Gestion des versions

Le code source est conservé dans le dépôt GitHub TaskFlow_groupe10. Les modifications sont enregistrées avec des commits. Les pull requests permettent de proposer et de faire réviser les changements avant leur intégration.

5. Suivi des tâches

Les tâches sont suivies dans GitHub Projects avec les colonnes suivantes :

À faire

En cours

À vérifier

Terminé
